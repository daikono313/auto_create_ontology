# 0007. すべての要素に根拠引用を必須にし、機械的に照合する

- ステータス: 承認
- 日付: 2026-10-23

## コンテキスト

LLM はもっともらしい概念を作り出せてしまう。叩き台としてレビューする人も、顧客に説明する人も、
「この定義はどこから来たのか」をすぐ確認できる必要がある。

## 決定

- Object / Property / Link / Action はそれぞれ `evidence`（URL と逐語の引用）を持つ。Property は任意、それ以外は必須とする。
- 生成後に、引用が実際のページ本文、または LLM に渡したページ要約の中に存在するかを照合する（`generate.verify_evidence`）。
  一致しなかった引用はレポートの末尾に列挙する。
- 推定した要素（画面にない Basket など）は、description に【推定】と書いたうえで、推定の根拠となった箇所を引用させる。

## 検討した代替案

- 根拠なしで出力する: レビューのコストが高く、ハルシネーションに気づけない
- LLM に自己検証させる: コストがかかるうえ確実ではない。文字列の照合なら安く確実にできる

## 結果

- 初回の実行では 41 件中 7 件が不一致だった。原因は LLM ではなく前処理の整形（`h1:` の接頭辞、パンくずの結合）だった。
  ページ要約も照合の対象にし、パンくずの整形を直したところ 53/53 件が一致した。
- 照合は「引用が存在するか」だけを見ている。引用が主張を支えているかどうか（意味的な妥当性）は人のレビューに任せる。
