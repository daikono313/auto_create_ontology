# 0001. ADRで設計判断を記録する

- ステータス: 承認
- 日付: 2026-10-23

## コンテキスト

このプロジェクトは試行錯誤しながら進める。LLMの呼び方、出力形式、評価方法といった判断を後から見返すとき、
「なぜそうしたか」が残っていないと、同じ議論を繰り返したり、前提を知らないまま変更してしまったりする。

## 決定

設計上の判断は `docs/adr/` に ADR として残す。書式は `template.md` に従い、索引は `README.md` で管理する。

## 検討した代替案

- README に書く: 判断の経緯や却下した案まで書くと README が肥大化する
- コミットメッセージだけに残す: 一覧性がなく、見返しにくい

## 結果

判断の経緯をたどれるようになる。一方で、書く手間がかかるため `/write-adr` スキルで負担を下げる。
