# 0003. 開発・検証の対象サイト

- ステータス: 置換（→ 0011）
- 日付: 2026-10-23

## コンテキスト

最初の対象はECサイトとする。概念（商品・カテゴリ・バリエーション・カートなど）が分かりやすく、
ドメイン知識による答え合わせもしやすい。候補として Amazon も挙がったが、次の問題がある。

- 利用規約でスクレイピングが禁止されており、bot 対策も強い
- 扱う商品の種類が多すぎて、特定の分野に固有の概念を見つけにくい
- 多数の出品者が商品を出すマーケットプレイスなので、一般的なECとは構造が違う

## 決定

2段階で進める。

1. 開発用: books.toscrape.com
   スクレイピング練習用に公開されているサイトで、規約上の懸念がない。概念は少ない（本・カテゴリ・カート）。
2. 検証用: Shopify 系の中規模D2Cサイト（例: Allbirds）
   バリエーション・素材・コレクション・店舗など、ECらしい概念が揃っている。

どのサイトでも、クロールの前に robots.txt と利用規約を確認する。リクエスト間隔は既定で 0.5 秒以上空ける。

## 検討した代替案

- Amazon: 上記の理由で不採用
- 最初から実顧客のサイトを使う: 正解を作りにくく、規約確認の負担も大きい

## 結果

books.toscrape.com は概念が少ないので、ここで精度が高く出ても、実サイトで同じ精度が出るとは言えない。
検証用サイトの正解データを早めに作る必要がある。
